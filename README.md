# StratEval Public Release

This repository contains the manuscript, taxonomy definitions, prompt-bank templates, analysis scripts, and a sanitized sample of scenarios for StratEval.

## Repository Structure
- `paper/`: The LaTeX source and PDF of the manuscript.
- `taxonomy/`: YAML definitions of the failure mode taxonomy and escalation ladder.
- `prompts/`: Templates and patterns used for decomposed prompt-bank probing.
- `examples/`: A sample of 2 representative scenarios from each of the 10 canonical scenario families.
- `analysis/`: Core scripts for running evaluations and generating taxonomic statistics.

## Artifact Archive
Full model outputs, raw judge logs, and the complete scenario corpus are released separately through an archival data record (Zenodo/Hugging Face) to preserve a stable DOI-linked version of the evaluation materials.
